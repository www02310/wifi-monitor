# WiFi Monitor

这是一个用于 Windows 环境下的 WiFi 网络状态监控工具，核心目标是持续检测网络是否中断、是否退化，并在出现问题时记录证据与告警。

## 主要功能

- 3 层探测：网关 / 外网 / DNS
- 断网与弱网分离，区分“完全中断”和“网络仍通但质量较差”
- 自动故障确认与恢复判定
- 断网事件持久化记录
- WiFi 断开原因和网络诊断信息采集
- 站点可用性探测（如微信、腾讯会议、B站等）
- 吞吐测试与网络质量分析
- 本地 Web 看板与日志输出
- 邮件与本地告警通知

## 运行环境

- Windows 10 / 11
- Python 3.x
- 依赖常见 Windows 网络命令（如 `netsh`、`ipconfig` 等）

## 启动方式

```bash
python wifi_monitor.py
```

如果需要修改检测参数，可编辑配置文件：

- `config.json`
- `config.example.json`

## 目录说明

- `wifi_monitor.py`：主程序
- `data/`：数据库等数据目录
- `logs/`：日志目录
- `reports/`：生成的报表与证据
- `WiFi/`：相关资源目录
